## Возможности

- **`calc`** - вычисляет выражение с операторами **`+ - * / % //`**. Поддерживаются унарные **`+`** и **`-`** перед числом. Приоритеты операторов учитываются
- **`convert`** - переводит значения между единицами из одной группы:
   - длина: `mm`, `cm`, `m`, `km`
   - масса: `g`, `kg`
   - температура: `c`, `f`, `k`

## Использование

```bash
python -m toolkit --help
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
```

Выражение для `calc` нужно брать в кавычки, иначе оно разобьётся на отдельные аргументы

### Примеры

```text
$ python -m toolkit calc "2 + 3 * 4"
14
$ python -m toolkit calc "10 / 4"
2.5
$ python -m toolkit calc "2 * -3"
-6
$ python -m toolkit calc "7 // 2"
3

$ python -m toolkit convert 1000 --from mm --to m
1000 mm -> 1 m
$ python -m toolkit convert 1.5 --from KG --to g
1.5 KG -> 1500 g
$ python -m toolkit convert 0 --from c --to f
0 c -> 32 f
$ python -m toolkit convert -273.15 --from c --to k
-273.15 c -> 0 k
```

## Структура проекта

```text
src/toolkit/
├── __init__.py
├── __main__.py      # CLI: вывод и команды
├── calculator.py    # ядро калькулятора
├── converter.py     # ядро конвертера
├── constants.py     # операторы, приоритеты, группы
├── errors.py        # ToolkitError и его наследники
└── history.py       # модуль истории вычислений
tests/
├── test_calculator.py
├── test_cli.py
├── test_converter.py
└── test_history.py
```

**Калькулятор** использует несколько этапов:

1. **Токенизация** (`_tokenize`) - строка разбивается на токены (числа и операторы), `//` считается как один токен.
2. **Валидация** (`_validate`) - проверяется, что выражение арифметически корректно.
3. **Склейка унарных знаков** (`_merge_unary_signs`) - знак в начале выражения или после другого оператора присоединяется к числу.
4. **Перевод в обратную польскую запись** (`_to_rpn`) - алгоритм сортировочной станции Дейкстры с приоритетами из `constants.py`.
5. **Вычисление** (`_calculate_rpn`) - стеком.

**Конвертер** для массы и длины использует способ перевода через базовую единицу `value * множитель_из / множитель_в`. Для температуры отдельный случай. У каждой шкалы есть две функции: перевод в кельвины, перевод из кельвинов. Принцип перевода похож.

**История вычислений** каждая успешная команда записывается в `history.json` в корне проекта (путь лежит в `constants.py`). Пример записи:
```json
{
  "expression": "calc 2+3",
  "result": 5.0,
  "time": "2026-02-02 12:01:23"
}
```

## Принятые решения

- **Отрицательные длина и масса запрещены**, т.к. не имеют смысла.
- **Пробелы вокруг единиц игнорируются** `" KG "` понимается как `kg`.
- **Унарный знак** только один перед числом, например: `1+-2 = -1`, `2*-3 = -6`. Два знака подряд (`--3`) считаются ошибкой `unexpected_operator`.
- **Результат конвертера всегда `float`**.
- **Вывод чисел** в терминал не больше 10 значащих цифр. Очень большие результаты принтятся в `e` записи.
- **`//` и `%`** работают как в Python.
- **Сбой записи истории** не влияет на результат и код возврата. Если выражение получилось вычислить - программа вернет 0 и предупредит юзера.
